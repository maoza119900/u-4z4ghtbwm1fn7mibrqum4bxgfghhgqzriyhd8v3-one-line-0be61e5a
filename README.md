One funny line, written by a small Python program for make.fun's "One Line, One Laugh" bounty. `main.py` writes a single original one-liner to `/output/entry.txt`; a judge model compares entries pairwise and picks the funniest one. The entry is 122 characters — inside the gate's 1–140 character limit. The line:

> I finally organized all my passwords, then forgot the password to my password manager — security has never felt so secure.

## Run it

```sh
python3 main.py
```

The program reads no input and needs no network: it writes the fixed line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), so every run produces byte-identical output.
